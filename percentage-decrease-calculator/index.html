What a percentage decrease is

A percentage decrease says how big a fall is compared with where the value started. The base is always the old value. A fall from 80 to 60 is 20 less than 80, and 20 is 25% of 80, so the decrease is 25%.

percentage decrease = (old - new) / old x 100
new value           = old x (1 - decrease / 100)
old value           = new value / (1 - decrease / 100)

How to calculate it

  1. Subtract the new value from the old value to get the amount of the fall.
  2. Divide that amount by the old value, not the new one.
  3. Multiply by 100 to make it a percentage.

Worked example: a monthly bill drops from 240 to 204. The fall is 240 - 204 = 36. Divided by 240 that is 0.15, so the bill fell by 15%. The calculator's first box works the other way round: type 240 and 15 and you get 204.

When to use percentage decrease

Use it when one value is clearly the starting point and the other is lower: a price that was cut, sales that dropped, a bill that shrank, weight lost. If you are only comparing two numbers with no starting point, such as two measurements, use the percentage difference calculator, which uses the average of the two as the base. If the direction could be either way, the percent change calculator shows a minus sign for a fall. For the opposite case, a rise, use the percentage increase calculator.

Mistakes to avoid

  • Dividing by the new value. From 80 to 60, dividing 20 by 60 gives 33.33%, which is the rise needed to get back, not the decrease.
  • Adding successive decreases. Two cuts of 20% leave 0.8 x 0.8 = 0.64 of the value, which is 36% off, not 40%.
  • Mixing up a percentage decrease with a drop in percentage points.

What this calculator leaves out

It handles one fall at a time. For a price with a second discount stacked on top, or to find the percent off from two prices with the saving shown, use the discount calculator. It does not take tax or rounding into account, and a percentage fall is hard to read when the old value is negative or near zero, so for those cases look at the amount of the change as well. The guide to percentage formulas covers the common mistakes.

Frequently asked questions

How do I calculate a percentage decrease?

Subtract the new value from the old value, divide by the old value, and multiply by 100. From 80 to 60 is (80 - 60) / 80 x 100 = 25%.

How do I reduce a number by a percentage?

Multiply it by 1 minus the percentage as a decimal. Reducing 200 by 15% is 200 x 0.85 = 170.

How do I work out a sale price?

Multiply the original price by 1 minus the discount. A $50 item at 30% off costs 50 x 0.70 = $35. The discount calculator also shows the saving and stacked discounts.

What is the difference between percentage decrease and percentage difference?

Percentage decrease has a direction: it measures a fall from an old value and uses the old value as the base. Percentage difference compares two values with no starting point and uses their average as the base. For 80 and 60 the decrease is 25%, but the difference is 20 / 70 x 100 = 28.57%.

What do two discounts in a row add up to?

They multiply, they do not add. 20% off and then a further 10% off leaves 0.80 x 0.90 = 0.72 of the price, which is 28% off in total, not 30%.

If a value falls 50% and then rises 50%, do I get back to the start?

No. 100 falls to 50, and 50 rising by 50% is only 75. To get back you need a rise of 100%, because the rise starts from a smaller number.

Can a percentage decrease be more than 100%?

Not for a value that stays at zero or above: the most it can fall is to 0, which is 100%. It can pass 100% only if the value goes negative. From 20 to -5 is a fall of 125%.

How do I find the original number before a decrease?

Divide the new value by 1 minus the percentage as a decimal. If a price is 60 after a 25% cut, the original was 60 / 0.75 = 80.

Is a fall of 5 percentage points the same as a 5% decrease?

No. A rate going from 20% to 15% is down 5 percentage points, but it is a 25% decrease, because 5 / 20 x 100 = 25.

What happens if the new number is bigger than the old one?

The result is shown as an increase instead, with a plus sign. For a rise, use the percentage increase calculator, or the percent change calculator to see either direction.
