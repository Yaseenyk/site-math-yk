What percentage difference means

Percentage difference answers “how far apart are these two numbers, as a share of their size?” when neither number is the original. Because there is no starting point, the base is the average of the two values. That makes the answer symmetric: it does not change if you swap them.

percentage difference = |a - b| / ((a + b) / 2) x 100

How to calculate it

  1. Subtract one number from the other and ignore the sign. That is the gap.
  2. Add the two numbers and divide by 2. That is the average.
  3. Divide the gap by the average and multiply by 100.

Worked example: two shops sell the same item for 48 and 54. The gap is 6. The average is 51. Then 6 / 51 x 100 = 11.76%. Neither shop is the “old” price, so neither is the base.

Which percentage should I use?

  • Percentage difference for two values on equal footing, with the average as the base.
  • Percent change when one value is the old value and you want the move from it, with a sign.
  • Percent error when one value is a known true or accepted value. Divide by that value instead of the average.

What this calculator leaves out

It compares two numbers only. For a list of numbers, the spread is described by the standard deviation. It gives no answer when the two numbers average to zero, because the base would be zero. It also does not say which value is larger; the extra line under the result shows the change in each direction. For a plain rise or fall from a starting value, see the percentage increase and percentage decrease calculators. The guide to percentage formulas explains when each applies.

Frequently asked questions

How do I calculate the percentage difference between two numbers?

Divide the gap between them by their average, then multiply by 100. For 40 and 50 the gap is 10 and the average is 45, so the difference is 10 / 45 x 100 = 22.22%.

What is the difference between percentage difference and percent change?

Percent change measures a move from an old value to a new one and uses the old value as the base. Percentage difference compares two values neither of which is the starting point, using their average as the base, so the order does not matter.

Why not just divide by one of the numbers?

Then the answer would depend on which number you chose. Using the average treats both equally: 40 and 50 give 22.22% in either order, while a change from 40 to 50 is +25% and from 50 to 40 is -20%.

When should I use percentage difference?

When you compare two measurements of the same kind with no obvious starting point, such as two lab results, two prices from different shops, or two estimates.

What if one number is zero?

It still works as long as the average is not zero. 0 and 10 have an average of 5, so the difference is 10 / 5 x 100 = 200%. Two numbers that cancel, such as -5 and 5, have an average of 0 and no percentage difference.

What is the largest possible percentage difference?

For two numbers that are zero or positive it is 200%, reached when one of them is 0. Always being at or below 200% is one reason it behaves differently from percent change, which has no upper limit: 10 to 100 is +900%, while the difference between 10 and 100 is 163.64%.

Is percentage difference the same as percent error?

No. Percent error compares a measured value with an accepted or true value and divides by that accepted value: |measured - true| / |true| x 100. Percentage difference has no true value, so it divides by the average of the two. Use percent error when one number is the reference.

Can the percentage difference be negative?

No. It uses the size of the gap, so it is always zero or positive, and it is zero only when the two numbers are equal. If you need to know which value is bigger, use percent change.

How do I turn two numbers into a percentage difference in a spreadsheet?

With the values in A1 and B1, enter =ABS(A1-B1)/((A1+B1)/2) and format the cell as a percentage.

Does the order I type the numbers in matter?

No. That is the point of the measure. 40 and 50 give 22.22%, and so do 50 and 40.
